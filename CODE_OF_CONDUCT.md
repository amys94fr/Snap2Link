# Code of Conduct

Snap2Link adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its Code of Conduct.

The full text is available at the link above. In short:

- **Be welcoming and inclusive.** Newcomers, beginners, and people from different backgrounds make the project better.
- **Be respectful.** Disagree with ideas, not with people. Critique code, not authors.
- **Be patient.** Maintainers and contributors are volunteers. Replies may take time.
- **Be honest.** Acknowledge mistakes (yours and the project's), and work to fix them.

Behaviour that does not meet these standards is not acceptable in any project space — issues, pull requests, discussions, commit messages, code review comments, or any direct communication that happens because of the project.

## Reporting

If you observe or experience behaviour that breaks this Code of Conduct, please contact the project maintainer privately:

- Email: **amys94fr@gmail.com**, subject line `[Snap2Link CoC]`
- Or [open a private security advisory](https://github.com/amys94fr/Snap2Link/security/advisories/new) (the same channel as security reports — it stays private).

All reports will be reviewed and investigated promptly and fairly. The maintainer is obligated to respect the privacy and safety of the reporter.

## Enforcement

Project maintainers may take any action they deem appropriate, up to and including a permanent ban from the project's spaces, for behaviour that breaks this Code of Conduct. Decisions can be appealed by emailing the maintainer.

The full enforcement guidelines (impact levels and corresponding consequences) are described in the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
