# Snap2Link

> Capture a screen region and instantly get a Google Drive share link in your clipboard.

A native desktop app built with **Tauri v2 + React/TypeScript**, available for Windows
and macOS. Tray-resident — press `Ctrl + PrintScreen` (or click the tray icon),
drag a rectangle, and a public Drive link is on its way to your clipboard.

---

## Features

- 🎯 **Region selection overlay** — fullscreen, drag to capture, ESC to cancel
- ☁️ **Auto-upload to Google Drive** via OAuth 2.0 (your screenshots, your drive)
- 🔗 **Public direct-download link** copied automatically to your clipboard
- ⚡ **Global hotkey** (default `Ctrl+PrintScreen`, configurable) so it works from anywhere
- 🧹 **Auto-cleanup** of old screenshots (configurable retention, default 30 days)
- 🪟 **Starts with Windows** (toggleable) so it's always one keystroke away
- 🔄 **Built-in updater** — Settings → Check for Updates pulls signed releases
- 🌍 **i18n-ready** — English bundled; add a locale by translating one JSON file

## Installation

Pre-built installers are published on the
[Releases page](https://github.com/amys94fr/Snap2Link/releases) once a version
is cut. For now, build from source:

```bash
git clone https://github.com/amys94fr/Snap2Link.git
cd Snap2Link
npm install
npm run tauri dev
```

You also need a `credentials.json` at the repo root — see the *Google Drive
setup* section below.

## Google Drive setup (one-time)

1. Go to [console.cloud.google.com](https://console.cloud.google.com).
2. Create a project and enable the **Google Drive API**.
3. Credentials → OAuth client ID → **Desktop application** → download the JSON.
4. Rename it to `credentials.json` and drop it at the project root
   (it's gitignored, never committed).

On first run the app's setup wizard handles the OAuth dance.

## Development

```bash
npm install
npm run tauri dev          # dev build with hot reload
npm test                   # frontend unit + component tests (Vitest)
cd src-tauri && cargo test --lib   # Rust unit tests
```

The codebase is fully TDD-covered: 77 frontend tests + 24 backend tests. The
Rust backend is split between pure helpers (testable in isolation) and Tauri
command wrappers.

### Project layout

```
src/                # React/TypeScript frontend
  windows/          #   four windows (SetupWizard, Settings, About, Overlay)
  components/       #   shared UI: HotkeyRecorder, RetentionControl, UpdateChecker
  i18n/             #   i18next + locales/en.json
  store/            #   Zustand global state
  lib/keyMap.ts     #   KeyboardEvent → Tauri shortcut format

src-tauri/          # Rust backend
  src/commands/     #   auth, config, drive, screenshot, updater
  src/tray.rs       #   system tray icon + menu
  src/hotkey.rs     #   global shortcut registration
  icons/            #   app icons (all sizes, generated by `cargo tauri icon`)
```

## Build & release

Bundle a signed installer:

```bash
npm run tauri build

```

For the full release procedure (signing, manifest, GitHub Releases setup), see
